# Administrator setup

Start here if you are the Domino administrator preparing the workshop. Do this once, before participants arrive.

**Follow the guide:** [`admin-setup-guide.html`](admin-setup-guide.html) (open it in a browser), or
[`admin-setup-guide.pdf`](admin-setup-guide.pdf) if the HTML will not open.

It covers the compute environments, hardware tiers, the optional code assistant environment, the optional
Oracle GPU data plane notes, and a test and hand-off checklist.

| File | What it is |
| --- | --- |
| `admin-setup-guide.html`, `admin-setup-guide.pdf` | The step-by-step admin guide |
| `environments/Dockerfile` | Dockerfile instructions for the `Fraud-Detection-Workshop` environment |
| `environments/Dockerfile.llm` | Dockerfile instructions for the `Fraud-Detection-LLM` (GPU) environment |
| `environments/environment.md` | Longer notes on how the workshop environment is built |

When you are done, participants follow the guide in the [`user/`](../user/) folder.
