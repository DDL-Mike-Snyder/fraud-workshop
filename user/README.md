# Participant guide

Start here if you are taking the workshop. Your administrator should have finished the setup in the
[`admin/`](../admin/) folder first, so the compute environments and hardware tiers already exist.

**Follow the guide:** [`fraud-workshop-guide.html`](fraud-workshop-guide.html) (open it in a browser), or
[`fraud-workshop-guide.pdf`](fraud-workshop-guide.pdf) if the HTML will not open.

Step 1 of the guide shows two ways to start:
- **Git (recommended):** fork this repository on GitHub and create a Git-based project in Domino from your fork.
- **Domino-hosted:** download the two files in [`downloads/`](downloads/) and upload them to a new project.

| File | What it is |
| --- | --- |
| `fraud-workshop-guide.html`, `fraud-workshop-guide.pdf` | The step-by-step workshop guide |
| `downloads/fraud-workshop-code.zip` | The project code, for the upload option |
| `downloads/fraud-workshop-data.zip` | The raw transactions (78,324 rows) |

The project code itself (`exercises/`, `app.sh` and the other files at the top of the repository) is what Domino
runs. You do not need to open it to follow the guide.
